# PHILSS

Golf shop and travel website for **PHILSS**. Cloned from the Unotour PH storefront: products, checkout, accounts, and admin.

## Local setup

1. Copy `.env.example` to `.env` and add Supabase / payment keys.
2. Install and run:

```bash
npm install
npm run dev
```

Docker (host port **3011**):

```bash
docker compose up --build
```
